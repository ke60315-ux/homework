# 🌿 Taiwan Weather Forecast

淡綠文青風的台灣一週天氣預報作品，串接 **中央氣象署 CWA Open Data**，使用 **Python + Streamlit** 製作，API Key 透過 **Streamlit Secrets** 管理，不會放在公開 GitHub 原始碼中。

- 💻 **專案原始碼**：[`taiwan_weather_forecast/`](./taiwan_weather_forecast/)

## ✨ 功能

- 台灣縣市切換
- 一週最高／最低溫
- 溫度趨勢折線圖
- 每日預報資料表
- 中央氣象署即時 JSON 資料
- 淡綠色文青風響應式介面
- API Key 隱藏於 Streamlit Secrets

## 🧰 技術

`Python` · `Streamlit` · `Requests` · `CWA Open Data API` · `GitHub` · `GitHub Pages`
